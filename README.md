# 🎓 Student Management System

一个基于 Python 开发的命令行学生信息管理系统，实现学生信息的增删改查、成绩排名及统计分析。项目使用 CSV 文件进行数据持久化，主要用于巩固 Python 基础知识与实践编程能力。

## 📌 项目介绍

本项目是一个 Python 入门实践项目，采用命令行交互方式，模拟简单的学生信息管理场景。

通过本项目，实践了 Python 数据结构、函数封装、文件读写、正则表达式、异常处理等知识。

## ✨ 功能介绍

- **学生信息添加**：录入学生姓名、学号、性别和成绩。
- **学生信息删除**：根据学号查找并删除指定学生。
- **学生信息修改**：支持修改学生的个人信息。
- **查看全部学生**：以表格形式展示学生信息。
- **成绩排名**：根据考试成绩进行降序排列。
- **成绩统计**：计算最高分、最低分和平均分。
- **数据持久化**：通过 CSV 文件保存学生信息，程序重新启动后仍可读取数据。
- **输入验证**：使用正则表达式验证输入格式，并限制学号和成绩范围。

## 🛠️ 技术栈

| 技术 | 应用 |
|---|---|
| Python | 核心开发语言 |

## 🚀 运行方法

### 1. 克隆项目

```bash
git clone <https://github.com/C1X-start/Student_manage.git>
```

### 2. 进入项目目录

```bash
cd Student-Management-System
```

### 3. 运行程序

```bash
python student.py
```

项目使用 Python 标准库，无需额外安装第三方依赖。
